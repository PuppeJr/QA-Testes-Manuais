# Massa de Testes

## Objetivo

Esta pasta contém todas as massas de teste utilizadas durante a execução dos casos de teste.

## Fluxo

Plano de Testes
        ↓
Caso de Teste
        ↓
Massa de Testes
        ↓
Execução
        ↓
Evidência

## Documentos

MT-001 — Conta Google válida

MT-002 — Usuário válido

MT-003 — Navegadores

## Convenções

MT = Massa de Testes

Cada massa deve:

• possuir ID único
• possuir rastreabilidade
• possuir histórico
• ser utilizada por um ou mais CTs

## Relacionamentos

PT → CT → MT → ET → EV → BUG
